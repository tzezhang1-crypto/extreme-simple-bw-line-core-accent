# 極致簡單黑白線稿加核心資訊顏色標示

將教學內容轉成學生看得懂、畫得出、記得住的視覺。以黑白線稿為主體，只用低飽和色彩標示每頁 2–4 類核心資訊。

## 適用情境

- 國小教學投影片
- 故事地圖與概念圖
- 流程圖
- 可列印學習單
- 需要學生模仿或重畫的教學視覺

## 視覺特色

- 使用粗而清楚的黑色外輪廓。
- 將人物、物件與動作簡化成圓、橢圓、矩形、三角形及基本線條。
- 讓非核心元素退到黑、深灰或淺灰。
- 每頁只突出 2–4 類核心資訊。
- 保留足夠空白，避免文字、作答區與圖像互相干擾。
- 使用克制的低飽和色彩，而非全彩裝飾。

## 不適用情境

- 需要照片或寫實影像的任務
- 全彩插畫或精緻寫實作品
- 品牌主視覺
- 裝飾性海報
- 需要大量細節的畫面

## 使用方式

1. 先找出本頁唯一的教學主張。
2. 拆出 2–4 個可看見的核心資訊主角。
3. 將主角降解成學生能模仿的基本形。
4. 以黑白線稿建立主要畫面。
5. 最後加入少量色彩標示核心資訊，並檢查文字與空白區域的可讀性。
