# 極致簡單黑白線稿加核心資訊顏色標示

這是一套面向教學簡報與學習單的視覺 Skill：以學生可以實際仿畫的極簡黑白線稿呈現內容，只為每頁 2–4 個核心資訊加上低飽和色彩，提升辨識度與教學聚焦。

本儲存庫以《愛心樹》教學簡報為成果範例，包含三個 PDF 版本與可重複使用的 Codex Skill。

## 視覺原則

- 以粗黑外框、基本形狀與少量內部線條呈現人物、樹木、物品和流程。
- 移除寫實明暗、材質紋理、陰影、細密葉脈與不必要的背景細節。
- 文字、箭頭與主要結構維持黑色或灰色。
- 每頁只標示 2–4 類核心資訊，使用一致的低飽和橄欖綠、蘋果紅、石板藍與赭黃色。
- 保留故事因果順序、教學重點與學習單的書寫空間。

## Skill 適用情境

適合用於：

- 國小教學簡報
- 故事地圖與段落摘要
- 概念圖、流程圖與課堂講解圖
- 學習單與學生仿畫素材

不適合用於需要照片寫實、複雜裝飾或全彩品牌視覺的簡報。

## 建議使用流程

1. 先找出每頁唯一的教學主張。
2. 選定 2–4 個需要被看見的核心資訊主角。
3. 把其他元素降為黑白或灰階。
4. 將圖像簡化成學生能模仿的基本形狀。
5. 最後才配置核心資訊的色彩與版面。
